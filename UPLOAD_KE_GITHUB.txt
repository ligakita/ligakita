LIGA KITA VOL-I — PAKET GITHUB PAGES

Upload SEMUA file di folder ini ke repository:
ligakita.github.io

File utama:
- index.html
- style.css
- app.js
- firebase-config.js
- logo-liga-kita.jpg
- admin.html
- admin.js

Jangan hanya upload index.html, karena website membutuhkan CSS, JavaScript,
logo, dan konfigurasi Firebase.

Setelah semua file di-upload:
Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save

Alamat target:
https://ligakita.github.io

Website ini memakai Firebase yang sama seperti versi Liga Kita sebelumnya,
sehingga struktur publik + admin tetap dipertahankan.
